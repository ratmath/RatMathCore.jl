API Reference

RatMathCore.BaseSystem — Type
BaseSystem(characters, name="")

A custom positional digit alphabet.

Digits are zero-indexed by position in characters. Reserved parser symbols such as +, /, :, ., #, and ~ are rejected.

Examples

julia> binary = BaseSystem("01", "Binary");

julia> to_decimal(binary, "1010")
10
RatMathCore.Fraction — Type
Fraction(n, d=1; allow_infinite=false)
Fraction(s; allow_infinite=false)

An unreduced numerator/denominator pair.

Unlike Julia's Rational, Fraction(2, 4) and Fraction(1, 2) are distinct values. Limited infinite sentinels 1/0 and -1/0 are allowed only when allow_infinite=true.

Examples

julia> Fraction(2, 4) == Fraction(1, 2)
false

julia> rational(Fraction(2, 4))
1//2

RatMathCore.RationalInterval — Type
RationalInterval(a, b)

An exact closed interval over Rational{BigInt} endpoints.

The original endpoint order is kept as start and stop; ordered mathematical bounds are stored as low and high.

Examples

julia> RationalInterval(2, 1)
2:1

julia> RationalInterval(2, 1).low
1//1

RatMathCore.rat — Function
rat(x)
rat(n, d)
rat(s::AbstractString)

Construct an exact Rational{BigInt}.

rat is the RatMath-friendly constructor for Julia's built-in rational type. It accepts integers, integer numerator/denominator pairs, existing rationals, and RatMath-style strings.

Supported string forms include integers, fractions, terminating decimals, and mixed numbers using whole..numerator/denominator.

Examples

julia> rat("5..2/3")
17//3

julia> rat("-0.125")
-1//8
