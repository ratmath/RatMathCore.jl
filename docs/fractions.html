Unreduced Fractions

Fraction preserves numerator and denominator exactly as entered.

This is different from Julia's Rational, which always reduces.

using RatMathCore

Fraction(2, 4) == Fraction(1, 2)
false
rational(Fraction(2, 4))
1//2

Arithmetic

Addition and subtraction intentionally require equal denominators. This preserves the RatMath JavaScript behavior.

Fraction(1, 4) + Fraction(2, 4)
3/4
Fraction(1, 2) / Fraction(3, 4)
4/6
reduce_fraction(Fraction(4, 6))
2/3

Mediant

The mediant of $a/b$ and $c/d$ is:

\[\frac{a+c}{b+d}\]

mediant(Fraction(1, 3), Fraction(1, 2))
2/5

Stern-Brocot Paths

path = stern_brocot_string(Fraction(3, 5))
"RLRL"
from_stern_brocot_path(path)
3/5

Fraction Intervals

FractionInterval preserves unreduced fraction endpoints.

fi = FractionInterval(Fraction(1, 3), Fraction(1, 2))
mediant_split(fi)
(1/3:2/5, 2/5:1/2)
partition_with_mediants(fi, 2)
4-element Vector{FractionInterval}:
 1/3:3/8
 3/8:2/5
 2/5:3/7
 3/7:1/2
