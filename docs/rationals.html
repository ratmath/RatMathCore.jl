Exact Rationals

Julia already has an excellent exact rational type: Rational{T}. RatMathCore.jl uses Rational{BigInt} as its reduced rational representation.

Use rat for RatMath-style construction.

using RatMathCore

rat(6, 8)
3//4
rat("1.25")
5//4
rat("-2..1/4")
-9//4

Exact Division

Julia's / returns floating-point results for integers. RatMath-style exact division is available through exact_div.

exact_div(6, 3)
2
exact_div(5, 2)
5//2

Mixed Numbers

RatMath mixed numbers use whole..numerator/denominator.

to_mixed_string(17//3)
"5..2/3"

Repeating Decimals

RatMathCore.jl uses # to mark the repeating part:

  • #0 means a terminating decimal.
  • #digits means digits repeat forever.
repeating_decimal(1//2)
"0.5#0"
repeating_decimal(1//3)
"0.#3"
repeating_decimal_with_period(1//7)
(base_string = "0.#142857", decimal = "0.#142857", period = 6, limit_hit = false)

Scientific Notation

Scientific notation remains exact in the sense that it is derived from exact rational metadata.

scientific_notation(1//7; show_period_info=true)
"0"
